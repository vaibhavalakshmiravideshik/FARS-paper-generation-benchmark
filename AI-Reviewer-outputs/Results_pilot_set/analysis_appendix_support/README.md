# Appendix Support Analyses

This folder contains additional analyses prepared specifically to support appendix material for the Discover AI manuscript without changing the main paper narrative.

## Files

- `reviewer_agreement_complete_cases.csv`: Complete-case Spearman correlations between reviewer overall scores, including sample sizes and p-values.
- `framework_summary_with_variability.csv`: Mean, median, standard deviation, minimum, maximum, and reviewer disagreement summary by framework.
- `synthesis_dimension_distribution_summary.csv`: Distribution summary for synthesis scores by framework and dimension.
- `per_paper_reviewer_disagreement.csv`: Per-paper reviewer disagreement metrics across GPT-5.4, Gemini 3.1 Pro, and Claude Opus 4.6.
- `proposal_level_synthesis_dimension_scores.csv`: Proposal-level synthesis scores for quality, clarity, significance, originality, and overall assessment.
- `score_missingness_summary.csv`: Missingness summary for the main reviewer score columns.
- `overall_score_distributions_by_reviewer.png`: Reviewer-specific distribution plots for appendix use.
- `reviewer_disagreement_by_framework.png`: Framework-wise reviewer disagreement plot for appendix use.

## Notes

These analyses are supplementary to the existing files in `analysis_ai_scientists_comparison/`. They emphasize variability, reviewer agreement, missing-data transparency, and proposal-level detail that can be moved into the appendix.
